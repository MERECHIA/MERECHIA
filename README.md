## What I've built

- **MARÉ** (3rd place, Rolê que Rende hackathon): a team web app supporting people affected by problematic online betting. I came up with the initial idea, designed the 3D water-glass exercise, integrated Mari, an AI support assistant using the Gemini API, and coordinated development with Claude Code, including the Git workflow, deployment and automated tests. After the hackathon, I kept improving Mari on my own: I redesigned its crisis detection in two layers and evaluated it on phrase sets never used for tuning. [Live app](https://mare-app-delta.vercel.app/) · [Mari's code](https://github.com/MERECHIA/mari-assistente)
- **AI Job Alert Triage**: a Google Apps Script automation that reads the job alerts in my Gmail, evaluates each job with the Gemini API, logs the results to Google Sheets with a Looker Studio dashboard and sends one daily summary. Over three days, it analyzed 80 jobs and cut my triage from about 27 to 4 minutes a day. [Code](https://github.com/MERECHIA/triagem-vagas) · [Dashboard](https://datastudio.google.com/reporting/d3cd77bc-c6ca-4dbe-ba1f-81935841e5cc)
- **Real ou Fake**: a solo MVP selected among the top three projects of the course and presented at the TCU (Tribunal de Contas da União) AI Fair. Users judge whether animal images are real or AI-generated, and the Gemini API gives contextual hints after a wrong answer. I built the original version with GitHub Copilot and later redesigned it with Claude Code. [Live app](https://realoufake.vercel.app) · [Original code](https://github.com/MERECHIA/real_ou_fake_public)
- **Restaurant Order Management System**: a full-stack web app for order tracking, built with PHP, MySQL, and JavaScript. [Code](https://github.com/MERECHIA/kebab-shop)
